# Samvedna Homeopathy CRO Content Audit

Scope: optimize messaging, trust, and conversion copy inside the existing landing page structure. No new landing page sections were added.

## Header / Navigation

Status: Update

Current Issues:
- External navigation links can pull parents away before they reach the consultation form.
- "DISEASE" is less parent-friendly than "Conditions."
- The CTA label "ONLINE-CONSULTING" feels transactional and unclear.

Recommended Changes:
- Keep the header structure.
- Replace navigation labels with in-page conversion anchors.
- Replace the main header CTA with "Book Consultation."

New Content:
- HOME
- CONDITIONS
- ABOUT DOCTOR
- CARE PROCESS
- PARENT STORIES
- FAQ
- CONTACT
- CTA: Book Consultation

Conversion Benefit:
- Keeps parents in the landing page flow and makes the primary action easier to understand.
